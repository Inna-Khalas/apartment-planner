# Планировщик объединения квартир 403+404

Интерактивный план объединённой квартиры №403 (68.89) + №404 (41.22).

- **91.01 м²** без балконов (в шапке и сводке по умолчанию)
- Балконы **19.10 м²** отдельно (7.30 / 3.90 / 3.10 / 4.80)
- Один главный вход (бывший 403), вход 404 → кладовая/техзона
- Один широкий проём в межквартирной стене
- Концепт для обсуждения, **не** рабочий проект для БТИ

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui

## Запуск

```bash
npm install
npm run dev
```

Приложение слушает порт **43147** (см. `package.json`).

Откройте [http://127.0.0.1:43147](http://127.0.0.1:43147).

## Возможности

- Pan/zoom по плану (перетаскивание, колёсико)
- Клик по зонам, легенда, сводка площадей
- Режим правки: перетаскивание мебели, слои, подписи, выбор балкона под остекление (или «ещё не решили»)
- Состояние сохраняется в `localStorage`
